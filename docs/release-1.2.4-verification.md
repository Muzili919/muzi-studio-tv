# 1.2.4 实机验证与发布边界

发布桌面125（1.2.4）和播放器422（4.0.7-muzi.10），Android 6/API 23。两个最终APK在两台Android 6设备上的安装包SHA256与发布文件一致。

- 同签名覆盖安装成功，升级前后既有观看记录逐项一致；片源URL集合和直播名称保留，缓冲档位3。
- HOME键在两台设备回到木子桌面，保留原系统语音服务。旧小米调试工具会影响辅助服务绑定，测试结束已恢复。
- 带麦克风遥控器的设备，经使用者确认语音文字进入木子影界搜索框。无麦克风的设备不声称支持实体语音。
- 点播已实际播放，使用者确认画面和声音正常。部分旧直播线路仍有上游直播窗口或有效性问题，未声称所有频道正常。
- OTA使用同签名修复桥接版完成后台下载、摘要和包信息校验、播放器及桌面依次安装。最终播放器的小修订通过同签名覆盖安装核验。未把ADB覆盖当作原1.1.4跨签名OTA通过。

1.1.4缺少旧签名，不能直接覆盖；部分旧1.1.6/1.1.7需要先手动修复一次。普通电视可能要求系统安装确认。客户默认桌面、自启动、语音和固件广告能力依赖电视授权与厂商实现，不能仅由APK保证。
